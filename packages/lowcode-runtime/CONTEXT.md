# 页面运行时

页面运行时负责把页面 Schema 呈现为可交互页面，同时保持对编辑器状态、宿主身份和部署框架的独立。

## Language

**页面运行时**：
接收页面 Schema、运行时物料注册表和宿主策略，负责渲染组件、执行事件及读取声明式数据源的无状态内核。
_Avoid_：编辑器预览、公开发布站、React 页面

**运行时物料注册表**：
页面运行时可使用的生产物料、默认属性、事件和父子约束集合，不包含设计态 setter 或拖拽行为。
_Avoid_：编辑器物料面板、设计态注册表

**宿主策略**：
编辑器或发布站注入页面运行时的能力边界，包括身份令牌、custom JS、请求域名和错误报告方式。
_Avoid_：全局环境变量、隐式默认权限
