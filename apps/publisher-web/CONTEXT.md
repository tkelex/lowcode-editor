# 公开发布运行时

公开发布运行时面向匿名访客呈现公开页面，与创作者的编辑状态和身份能力隔离。

## Language

**公开页面**：
访客通过公开地址访问的页面，只反映当前发布快照。
_Avoid_：页面草稿、编辑器预览

**公开发布运行时**：
以匿名身份呈现发布快照的受限运行环境，不继承编辑器预览的受信任能力。
_Avoid_：编辑器预览、设计态运行时

**发布物料依赖**：
随发布版本保存的不可变远程物料元数据；项目之后安装或升级物料不会改变既有公开页面引用。
_Avoid_：项目当前启用版本、latest、服务端执行远程代码

**发布物料加载门控**：
Next.js 服务端只校验和传递发布快照元数据；浏览器客户端按发布版本自己的固定依赖完成 allowlist、manifest、SRI 与宿主注册后，才把合并后的运行时 registry 交给页面运行时。
_Avoid_：依赖未就绪先渲染、读取项目当前物料、在 Server Component 执行远程 JavaScript
