# 前端编辑器

前端编辑器负责维护页面草稿，并让创作者在发布前验证页面结构与交互。

## Language

**页面草稿**：
创作者当前正在修改的页面 schema；页面草稿变化不会自动改变访客正在访问的公开页面。
_Avoid_：发布快照、公开页面

**页面级本地草稿**：
按用户、项目和页面隔离保存在浏览器中的未保存组件树；只用于重新打开页面后的恢复，不代替服务端保存。
_Avoid_：全局编辑器状态持久化、自动保存到服务端

**页面草稿 revision**：
编辑器加载页面时取得、保存成功后更新的服务端乐观并发基线；冲突时由用户选择保留本地草稿或重新加载服务端版本。
_Avoid_：自动合并、PageVersion.versionNo

**编辑器预览**：
基于页面草稿运行的创作者预览，可包含只在受信任编辑环境中开放的能力。
_Avoid_：公开发布运行时、公开页面

**项目远程物料目录**：
编辑器通过项目远程物料读取接口取得当前启用的固定依赖，在浏览器加载并把 dev、prod、setter、event、method 与父物料接收关系批量合并进 registry；项目切换时必须清理上一项目的远程配置。
_Avoid_：只读取当前页面已使用依赖、跨项目保留旧 registry、服务端执行 IIFE

**编辑器状态订阅**：
组件只订阅自身渲染所需的 Zustand 字段；组件树修改保留未变化分支的引用，画布以 memo 节点边界跳过无关渲染。拖放合法性检查在判定时读取最新树快照，不让每个投放目标持续订阅整棵组件树。
_Avoid_：完整 store 订阅、原地修改组件树、以机器相关耗时作为 CI 硬阈值
