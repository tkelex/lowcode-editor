## 维护规则

- 同一事实只选择一个权威文档详细维护，其他位置只链接。
- 目录、命令、接口或架构变化时，同步更新对应权威文档。
- 已完成计划、临时看板、工具专属说明和通用教程不进入仓库文档。
- 实现细节与文档冲突时，以源码为准，并修正文档。
