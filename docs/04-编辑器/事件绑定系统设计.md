# 事件绑定系统

## Schema

事件配置统一保存在组件的 `props.onEvent`：

```json
{
  "onEvent": {
    "click": {
      "actions": [
        {
          "actionType": "toast",
          "args": { "msgType": "success", "msg": "提交成功" }
        }
      ]
    }
  }
}
```

registry 的 `events` 只声明物料支持的事件，不保存用户动作。事件名由 runtime 转成 React prop，例如 `click -> onClick`、`change -> onChange`、`finish -> onFinish`。

旧 `props.onClick.actions` 结构由 `@lowcode/schema` 迁移为 `onEvent`。新代码只写 `onEvent`。

## 动作类型

| actionType | 行为 |
| --- | --- |
| `toast` | 展示消息 |
| `url` | 归一化 URL 后跳转或新窗口打开 |
| `componentAction` | 调用目标组件 registry method |
| `componentControl` | 显示、隐藏、启用、禁用、设置值、清空、打开、关闭、提交或重置 |
| `confirm` | 确认后执行嵌套动作，可配置取消分支 |
| `condition` | 根据安全表达式执行真假分支 |
| `http` | 发起请求，将响应或错误写入 event data |
| `setVariable` | 写入页面运行态变量 |
| `setComponentProps` | 更新目标组件运行态 props |
| `setComponentStyles` | 更新目标组件运行态 styles |
| `custom` | 在允许 custom JS 的策略下执行脚本 |

动作按数组顺序执行。`disabled` 跳过当前动作；`stopPropagation` 可终止后续动作。嵌套动作遵守同一规则。

## 事件数据

`createEventData` 从原始参数提取稳定字段：

- 输入类事件：`value`、`checked`。
- 表单提交：`values`。
- 分页和日期等组件：对应值及原始 `args`。
- 所有事件保留 `args`，供高级动作使用。

表达式和模板可读取：

```text
event.*
variables.*
context.component
context.eventName
context.components
args.*
```

HTTP headers/body 支持 `{{ event.value }}` 这类模板。条件表达式和组件联动值默认通过安全表达式求值器执行。

## HTTP 动作

- URL 先由 `normalizeHttpActionUrl` 归一化。
- 配置 allowed origins 后，runtime 拒绝白名单外请求。
- `currentUser` 鉴权只在编辑器预览策略提供 token 时生效。
- 响应写入 `event.httpResponse`，错误写入 `event.httpError`。
- 可通过 `responseKey`、`errorKey` 写入自定义 event data 路径。
- 不能把后端密钥或数据库凭据写入页面 schema。

## 组件联动

`componentAction` 调用 registry 声明的方法。`componentControl` 提供常见可视化操作，并可从 `event`、`variables`、`context` 或 `args` 解析目标值。

运行时组件更新只影响当前预览或访客会话，不回写页面草稿。持久化修改必须经过编辑器 store 和保存 API。

## Custom JS

- 编辑器预览默认允许，用于受信任的设计态调试。
- 发布站固定禁用，`custom` 动作会被跳过。
- 脚本不能获得后端 secret、数据库连接或隐式用户 token。
- 扩大脚本上下文前必须同步安全文档和 runtime 测试。

## 所有权

- 类型、迁移、安全表达式和通用动作规则：`packages/lowcode-schema/src`。
- 动作执行、事件 props 注入和运行态数据：`packages/lowcode-runtime/src/events`。
- 事件编辑界面：`apps/editor-web/src/features/editor/components/Setting`。
- 物料事件与方法声明：`apps/editor-web/src/features/editor/registry/configs`。

修改事件能力时至少运行 `npm run test`、`npm run check:editor-props` 和相关 E2E。
