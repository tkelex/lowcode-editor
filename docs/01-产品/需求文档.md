# 低代码编辑器需求文档

## 产品定位

项目面向中后台页面搭建，目标是稳定支持“创建项目、搭建页面、配置数据与交互、保存版本、发布访问”的完整闭环，而不是覆盖所有低代码场景。

```text
创建项目 -> 创建页面 -> 拖拽物料 -> 配置属性/样式/事件
  -> 预览 -> 保存版本 -> 发布快照 -> 匿名访问
```

## 用户与权限

| 角色 | 能力 |
| --- | --- |
| owner | 管理项目、成员、页面及项目审计 |
| editor | 编辑、保存和发布页面 |
| viewer | 只读项目、页面和配置 |
| admin | 治理用户、项目、发布页和全局审计 |

权限必须由后端执行，前端按钮状态只提供交互提示。

## 当前范围

- 注册、登录、会话恢复和退出。
- 项目、成员、页面、版本与审计管理。
- 物料拖拽、组件树、属性、样式、事件、源码和大纲编辑。
- 页面撤销/重做、预览、保存、回滚、发布和取消发布。
- 独立 Next.js 发布站呈现匿名快照。
- 外部 API 数据源模型和 CRUD 页面 schema 生成。
- AI 页面草稿与受限 schema patch，确认后写入编辑器。
- 管理员后台、素材上传、自动化检查和 Docker 部署模板。

## 核心验收

1. 用户能从零创建项目和页面，并在刷新后恢复已保存 schema。
2. owner/editor/viewer 的读写权限与后端规则一致。
3. 编辑态和运行态物料遵守同一 schema 契约。
4. 版本可回滚，发布页固定读取 `publishedVersionId` 指向的快照。
5. 草稿更新不会自动污染公开页，取消发布后公开接口返回 404。
6. 发布站不执行 custom JS，也不携带当前用户 token。
7. 数据源与 AI 生成结果必须通过 schema 校验后才能应用。
8. 管理员禁用项目后，其公开页面不可继续访问。

## 非目标

- 多人实时协同编辑。
- 平台托管用户业务数据表和业务记录。
- 任意源码生成或生产环境执行不受控 JavaScript。
- 完整商业化组件市场和多端渲染体系。
