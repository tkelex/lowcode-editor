# 安全规范

## 身份与权限

- 业务接口默认需要 JWT；公开页面读取接口除外。
- 密码只保存 bcrypt hash，不返回 `passwordHash`。
- owner/editor/viewer 权限由后端 service 校验，不能依赖前端隐藏按钮。
- 管理员接口同时使用 JWT 与管理员 guard。
- 被禁用用户、项目或取消发布页面不能继续通过旧链接访问。

## Schema 与运行时

- 页面写入前必须迁移并校验组件树。
- 公开页只读取发布快照，不读取可编辑草稿。
- 发布 runtime 固定 `allowCustomJS=false`，不提供当前用户 token。
- 编辑器 custom JS 使用 `new Function`，只允许在受信任的设计态预览中执行。
- HTTP action 不得注入后端密钥；生产环境使用 allowed origins 收口请求目标。

## 输入与文件

- DTO 校验类型、长度和必填字段。
- 上传限制 MIME、大小和最终存储路径，防止路径逃逸 `UPLOAD_DIR`。
- URL 在执行前归一化并校验协议或 origin。
- 不向客户端暴露 Prisma、SQL、内部堆栈或连接信息。

## 环境与日志

- `.env`、JWT secret、数据库密码和模型 API key 不进入 Git。
- 生产 `JWT_SECRET` 使用足够长的随机值。
- `FRONTEND_ORIGIN` 只允许真实编辑器 origin。
- 日志不记录 Authorization、密码、连接串或完整请求体。
- 错误响应和日志使用 `requestId` 关联。

## 上线最低检查

1. 数据库不直接暴露公网，账号不使用默认密码。
2. `VITE_LOWCODE_HTTP_ALLOWED_ORIGINS` 和 publisher allowed origins 已收口。
3. publisher 与 server 的 revalidate secret 一致。
4. `UPLOAD_DIR` 和 volume 为持久化专用目录。
5. 匿名页面不执行 custom JS，也不携带编辑器会话。
6. 生产日志和构建产物不包含密钥。
