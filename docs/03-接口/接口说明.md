# API 说明

本文记录当前 API 分组、鉴权规则、关键请求和 schema contract。字段细节以 controller、dto、service 和 `src/shared/api/*` 为准。

## 基础信息

```text
本地后端：http://localhost:3000/api
前端配置：VITE_API_BASE_URL=http://localhost:3000/api
公开发布页配置：VITE_PUBLISHER_SITE_URL=http://localhost:5174
Next.js 发布页服务端配置：PUBLISHER_API_BASE_URL=http://localhost:3000/api
缓存失效配置：PUBLISHER_SITE_URL=http://localhost:5174，PUBLISHER_REVALIDATE_SECRET=<secret>
Token key：lowcode_editor_token
鉴权头：Authorization: Bearer <accessToken>
```

统一错误响应包含：

```json
{
  "statusCode": 400,
  "code": "PAGE_SCHEMA_INVALID",
  "message": "错误信息",
  "path": "/api/pages/1",
  "method": "PATCH",
  "requestId": "request-id",
  "timestamp": "2026-04-28T00:00:00.000Z"
}
```

## 鉴权边界

公开接口：

- `POST /api/auth/register`
- `POST /api/auth/login`
- `GET /api/public/pages/:publicId`
- `POST /api/revalidate/published-page`（Next.js 发布页运行时内部接口）

受保护接口：

- 项目、页面、版本、发布、素材、模板等业务接口需要 JWT。
- 管理员接口需要 JWT + `AdminGuard`。

项目角色：

| 角色 | 能力 |
| --- | --- |
| owner | 管理项目、成员、审计、页面、版本、发布、数据源模型 |
| editor | 读项目，创建/保存/发布/回滚页面，维护数据源模型 |
| viewer | 只读项目、页面、版本和数据源模型 |

| 方法 | 路径 | 说明 |

## Projects API

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/projects` | 项目成员 | 当前用户可访问项目 |
| POST | `/api/projects` | 登录用户 | 创建项目，自动成为 owner |
| GET | `/api/projects/:id` | 项目成员 | 项目详情 |
| PATCH | `/api/projects/:id` | owner | 更新项目 |
| DELETE | `/api/projects/:id` | owner | 删除项目 |
| GET | `/api/projects/:id/members` | 项目成员 | 成员列表 |
| POST | `/api/projects/:id/members` | owner | 添加成员 |
| PATCH | `/api/projects/:id/members/:memberId` | owner | 修改成员角色 |
| DELETE | `/api/projects/:id/members/:memberId` | owner | 移除成员 |
| GET | `/api/projects/:id/audit-logs` | owner | 项目审计 |

成员角色只支持新增或调整为 `editor/viewer`，不能通过成员接口新增或移除 owner。

## Pages API

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/projects/:projectId/pages` | 项目成员 | 页面列表 |
| POST | `/api/projects/:projectId/pages` | owner/editor | 创建页面 |
| GET | `/api/pages/:id` | 项目成员 | 页面详情 |
| PATCH | `/api/pages/:id` | owner/editor | 更新页面和 schema |
| DELETE | `/api/pages/:id` | owner/editor | 删除页面 |
| GET | `/api/pages/:id/versions` | 项目成员 | 版本列表 |
| POST | `/api/pages/:id/rollback` | owner/editor | 回滚到版本 |
| DELETE | `/api/pages/:id/versions/:versionId` | owner/editor | 删除未被公开页面引用的版本记录 |
| POST | `/api/pages/:id/publish` | owner/editor | 发布页面 |
| POST | `/api/pages/:id/unpublish` | owner/editor | 取消发布 |
| GET | `/api/public/pages/:publicId` | 公开 | 读取发布快照 |

当前 `publishedVersionId` 指向的版本不能直接删除；接口返回 `409 PAGE_VERSION_IN_USE`。取消发布会先清空该引用，随后版本才能删除。

发布和取消发布成功后，后端会在配置了 `PUBLISHER_SITE_URL` 和 `PUBLISHER_REVALIDATE_SECRET` 时调用 Next.js 发布页运行时：

```http
POST /api/revalidate/published-page
x-revalidate-secret: <PUBLISHER_REVALIDATE_SECRET>
content-type: application/json

{ "publicId": "<publicId>" }
```

该接口由 `apps/publisher-next` 提供，用于失效 `published-page:<publicId>` 缓存 tag。未配置缓存失效地址或调用失败时，发布/取消发布主流程不失败，但审计 metadata 会记录 revalidate 结果。

创建页面：

```json
{
  "name": "首页",
  "routePath": "/home"
}
```

保存页面：

```json
{
  "name": "首页",
  "routePath": "/home",
  "schema": {
    "schemaVersion": "1.0.0",
    "pageId": 1,
    "components": [
      {
        "id": 1,
        "name": "Page",
        "props": {},
        "desc": "页面",
        "children": []
      }
    ],
    "metadata": {
      "updatedAt": "2026-04-28T00:00:00.000Z"
    }
  }
}
```

回滚：

```json
{
  "versionId": 1
}
```

## Data Source Models API

数据源模型是项目级“外部 API + 字段映射 + 生成选项”配置，用来生成前端 CRUD 页面 schema。平台只保存配置，不保存用户业务记录，不生成业务数据库表，也不代理外部业务数据接口。

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/projects/:projectId/data-source-models` | 项目成员 | 数据源模型列表 |
| POST | `/api/projects/:projectId/data-source-models` | owner/editor | 创建数据源模型 |
| GET | `/api/data-source-models/:id` | 项目成员 | 数据源模型详情 |
| PATCH | `/api/data-source-models/:id` | owner/editor | 更新数据源模型 |
| DELETE | `/api/data-source-models/:id` | owner/editor | 删除数据源模型 |

创建或更新核心结构：

```json
{
  "name": "用户",
  "key": "user",
  "primaryField": "id",
  "listApi": {
    "url": "/external/users",
    "method": "GET",
    "responseDataPath": "data.items",
    "responseTotalPath": "data.total"
  },
  "detailApi": {
    "url": "/external/users/{{ variables.recordId }}",
    "method": "GET",
    "responseDataPath": "data"
  },
  "createApi": {
    "url": "/external/users",
    "method": "POST"
  },
  "updateApi": {
    "url": "/external/users/{{ variables.recordId }}",
    "method": "PATCH"
  },
  "fields": [
    {
      "key": "name",
      "label": "姓名",
      "type": "text",
      "required": true,
      "listVisible": true,
      "formVisible": true,
      "detailVisible": true
    }
  ]
}
```

校验边界：

- `key` 在项目内唯一，只支持小写字母、数字和下划线，且以字母开头。
- `fields` 不能为空，字段 `key` 不能重复，字段类型只支持 `text/textarea/number/boolean/date/select`。
- API URL 仅描述外部接口地址和模板；实际业务数据请求由生成页运行态的数据源或 HTTP action 执行。
- viewer 可读取配置，但不能创建、更新或删除。

## AI Page Builder API

AI 页面搭建接口需要 JWT，并且只允许项目 `owner/editor` 使用。接口只返回低代码 Page schema 草稿，不生成 React/Vue/HTML 源码，也不会把模型 API key 暴露给前端。服务端未配置 `AI_PROVIDER_API_KEY` 时，会返回本地规则生成的可编辑草稿，并在 `warnings` 中说明降级原因。

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| POST | `/api/projects/:projectId/ai/page-generation` | owner/editor | 基于项目上下文生成页面草稿 |
| POST | `/api/pages/:pageId/ai/page-generation` | owner/editor | 基于当前页面上下文生成页面草稿 |
| POST | `/api/projects/:projectId/ai/agent-runs` | owner/editor | 基于项目上下文创建 AI agent run |
| POST | `/api/pages/:pageId/ai/agent-runs` | owner/editor | 基于当前页面和组件树创建 AI agent run |
| GET | `/api/ai/agent-runs/:runId` | 项目成员 | 读取 agent run 状态和候选结果 |
| POST | `/api/ai/agent-runs/:runId/cancel` | 项目成员 | 取消仍在执行的 agent run |

请求：

```json
{
  "prompt": "生成一个用户管理页面，包含统计、列表和编辑表单",
  "target": "crud",
  "writeMode": "replacePage",
  "apiDescription": "GET /api/users 返回用户列表",
  "responseSample": {
    "data": {
      "items": [
        { "id": 1, "name": "张三", "status": "启用" }
      ]
    }
  }
}
```

响应：

```json
{
  "summary": "已生成用户管理页面草稿",
  "warnings": ["CRUD 生成器对接点已预留"],
  "assumptions": ["字段类型根据接口示例自动推断"],
  "components": [
    {
      "id": 1,
      "name": "Page",
      "props": {},
      "desc": "页面",
      "children": []
    }
  ],
  "metadata": {
    "source": "model"
  }
}
```

安全规则：

- AI 输出写入编辑器前必须通过物料白名单、组件树、父子关系和事件动作校验。
- AI 默认不得生成 `custom` action 或可执行脚本。
- AI agent run 会返回 `routeDecision`，用于说明自然语言请求被识别为 `crud-page`、`free-page`、`edit-selected`、`style-polish`、`bind-data-source`、`add-event-action` 或 `fix-page-issue`，以及本次选择的工具、置信度、命中原因和降级说明。
- AI agent 只能调用服务端白名单工具；工具只返回候选 schema、候选 patch 或校验结果，不直接保存、发布或访问任意外部系统。
- AI agent 的 CRUD 工具只返回候选 Page schema/components 和 CRUD 元信息，不直接保存数据源模型、创建页面或调用外部业务接口。
- AI agent 候选 patch 必须由用户确认后才能写入编辑器，应用时会重新校验 stale baseline、目标组件、父子关系和安全规则。
- 公开发布页继续通过 `<Preview allowCustomJS={false} />` 禁止自定义 JS。
- HTTP action 仍受现有 URL、headers、body 和 allowed origins 运行态规则约束。

## Schema Contract

组件节点：

```ts
{
  id: number;
  name: string;
  props: any;
  styles?: CSSProperties;
  desc: string;
  children?: Component[];
  parentId?: number;
}
```

页面 schema：

```ts
{
  schemaVersion: CURRENT_SCHEMA_VERSION;
  pageId?: number;
  components: Component[];
  metadata?: Record<string, unknown>;
}
```

关键规则：

- 前端保存前校验 `components`。
- 后端创建、保存、发布、回滚前都会先迁移再校验。
- AI 生成结果写入编辑器前会先通过 `validateAiGeneratedComponents` 校验，再由用户确认应用。
- `Page.schema` 是当前草稿。
- `PageVersion.schema` 是保存、回滚或发布时的快照。
- 公开页只读取 `publishedVersionId` 指向的版本快照。
- Next.js 公开发布页运行时同样只读取公开接口返回的发布快照，不直接访问数据库或 Prisma。
