# 测试与验收

## 自动化

| 范围 | 命令 |
| --- | --- |
| Lint | `npm run lint` |
| 架构边界 | `npm run check:architecture` |
| 编辑器 props 契约 | `npm run check:editor-props` |
| 编辑器构建 | `npm run build` |
| 发布站构建 | `npm run build:publisher` |
| API 构建 | `npm run build:server` |
| 单元与运行时测试 | `npm run test` |
| 编辑器主回归 | `npm run test:e2e:editor` |
| API 与权限 smoke | `npm run smoke:api` |

API smoke 需要 PostgreSQL、migration 和运行中的 API。

## 核心流程

1. 注册或登录。
2. 创建项目和页面。
3. 添加物料并配置属性、样式和事件。
4. 进入预览并退出。
5. 保存后刷新，确认组件树恢复。
6. 查看版本、回滚并再次保存。
7. 发布并通过独立 publisher 访问匿名页面。
8. 修改草稿，确认公开页仍保持旧快照。
9. 再次发布，确认公开页更新。

## 权限

- owner 可管理成员和项目审计。
- editor 可编辑、保存和发布。
- viewer 只能读取，写接口返回 403。
- 非成员不能读取项目页面。
- admin 可禁用用户或项目、取消发布并查看全局审计。

## AI 与 CRUD

- CRUD 请求应路由到确定性生成器。
- 生成页面必须带有效 Page 根节点、父子关系和数据源 contract。
- 事件/数据源 patch 必须通过 baseline 与 schema 校验。
- 候选未确认前不能修改编辑器 store。
- viewer 发起生成或应用候选应被拒绝。

## 发布安全

- 公开接口只返回发布快照。
- 取消发布、删除发布版本或禁用项目后的行为符合后端规则。
- 发布 runtime 不执行 custom JS，不使用编辑器 token。
- publisher metadata、缓存 tag 和 revalidate endpoint 正常。
