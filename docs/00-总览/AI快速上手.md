# AI 快速上手

本文件只说明如何表达任务。项目事实、命令和文件职责分别由 `AGENTS.md`、`项目上下文索引.md` 与 `FILE_MAP.md` 维护。

## 开始任务

1. 读取 `AGENTS.md`。
2. 从 `CONTEXT-MAP.md` 选择相关上下文。
3. 按 `项目上下文索引.md` 的任务路由读取必要源码。
4. 查看 `git status --short`，保留用户现有改动。
5. 先确认范围和验收标准，再修改文件。

## 推荐任务格式

```md
## 目标
本次必须实现的结果。

## 现象或背景
错误信息、复现步骤、截图或当前限制。

## 范围
允许修改的 module、页面或接口。

## 不做
本次明确排除的内容。

## 验收标准
1. 可观察行为
2. 错误、空、加载等状态
3. 必须通过的命令

## 相关资料
- 文件、截图、OpenSpec 或 Issue
```

UI 任务使用 `UI需求表达指南.md` 补充尺寸、对齐、状态、响应式和视觉参考。

## 输出要求

- 诊断：给出原因、证据文件和影响范围，不自动实施未授权修复。
- 实施：说明改动、验证和剩余风险。
- 评审：问题优先，按严重程度列文件与行号。
- 文档：说明哪个文件成为事实来源，删除了哪些重复入口。

验证命令按 `AGENTS.md#Validation` 选择，不在本文件复制维护。
