# 项目上下文索引

这是新协作者和新 AI 对话的低 token 项目入口。它只记录稳定事实、阅读路线和当前验证状态；具体实现以源码和专题文档为准。

## 一句话说明

这是一个 Vite + React + TypeScript + NestJS + PostgreSQL 的低代码编辑器，并新增 Next.js 公开发布页运行时。用户可以登录后创建项目和页面，维护项目级外部 API 数据源模型，生成可编辑的前端 CRUD 页面 schema，在编辑器中拖拽物料、配置属性/样式/事件，保存 schema，管理版本，回滚，并发布公开访问页面。

## 技术栈

| 层 | 技术 |

## 核心业务闭环

```text
注册 / 登录
  -> 创建项目
  -> 维护数据源模型或直接创建页面
  -> 从数据源模型生成 CRUD 页面 schema
  -> 或在 AI 面板输入 CRUD 请求，由 agent 调用 CRUD 生成器产出候选页面
  -> 创建页面
  -> 打开编辑器
  -> 读取并迁移 Page.schema
  -> 写入 Zustand 组件树
  -> 拖拽物料、配置属性/样式/事件
  -> 保存前校验 schema
  -> PATCH /api/pages/:id
  -> 后端迁移、校验并保存 Page.schema
  -> 创建 PageVersion
  -> 发布生成 publish 快照
  -> 访客访问 Next.js /publish/:publicId
```

## 关键约定

- 组件树根节点是 `Page`，通常 id 为 `1`。
- 组件节点结构：`{ id, name, props, styles, desc, children?, parentId? }`。
- 主 store 导出名保留历史拼写：`useComponetsStore`。
- 新拖拽 hook 使用 `useMaterialDrop`，历史拼写 `useMaterailDrop` 保留兼容。
- 新 Preview 路径使用 `components/Preview` 或 `runtime/Preview`，历史拼写 `components/Preivew` 保留兼容。
- 新源码面板路径使用 `components/Source`，历史拼写 `components/Sourse` 保留兼容。
- 公开发布页必须传 `allowCustomJS={false}`。
- Next.js 公开发布页运行时只承担公开页 SSR、metadata、缓存和水合，不替代 Vite 编辑器主应用。
- AI 页面搭建和 AI agent 只生成低代码 schema 或 schema patch；模型调用走后端，前端不持有模型 API key。
- AI 结果必须先校验和用户确认，再替换整页、插入当前容器或应用候选 patch。
- AI agent run 会返回 `routeDecision`，把自然语言请求识别为 CRUD 页面、普通页面、局部编辑、样式优化、数据源绑定、事件动作配置或问题修复，并展示置信度、原因、工具和降级说明。
- AI agent 识别 CRUD/数据源类请求时，优先读取已有数据源模型或推导临时 model draft，再调用确定性 CRUD 生成器产出 components candidate。
- 数据源模型只描述外部 API 和字段映射；平台不托管用户业务记录，不按模型生成业务数据库表。
- CRUD 生成器输出普通 Page schema，生成后继续走现有编辑、保存、版本和发布链路。

## 高风险区域

- `src/editor/stores/components.tsx`：组件树、选择、撤销重做、本地缓存。
- `src/editor/registry/component-config.tsx`：物料、setter、事件、方法、dev/prod 映射。
- `src/editor/runtime/Preview/index.tsx`：事件动作、运行态变量、数据源、自定义 JS。
- `apps/publisher-next/src/published-pages/*`：Next.js 公开发布页取数、metadata、缓存 tag 和 revalidate 入口。
- `server/src/modules/pages/published-page-revalidate.service.ts`：发布/取消发布后的 Next.js 缓存失效通知。
- `packages/lowcode-schema/src/*`：前后端 schema 迁移和校验。
- `packages/lowcode-schema/src/ai-*`：AI 页面生成/agent 类型、物料白名单、规范化、patch 应用和安全校验。
- `packages/lowcode-schema/src/data-model-crud-*`：数据源模型校验和 CRUD schema 生成。
- `server/src/modules/projects/project-access.service.ts`：项目成员权限。
- `server/src/modules/data-source-models/*`：数据源模型配置存储、权限和审计。
- `server/src/modules/pages/*`：页面保存、版本、发布、公开读取。
- `server/prisma/schema.prisma`：数据库模型，改动必须配套 migration。
