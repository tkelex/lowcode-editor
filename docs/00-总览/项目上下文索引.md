# 项目上下文索引

这是新协作者和 AI 的低 token 项目入口，只记录稳定事实和任务路由。领域术语见 `CONTEXT-MAP.md`，详细实现以源码和专题文档为准。

## 一句话说明

项目由 Vite 低代码编辑器、Next.js 公开发布运行时、NestJS 平台后端、PostgreSQL 和共享 schema 契约组成，覆盖页面编辑、保存、版本、发布、数据源与受限 AI 生成闭环。

## Contexts

| Context | 职责 | 入口 |
| --- | --- | --- |
| 前端编辑器 | 项目后台、页面草稿、设计与编辑器预览 | `src/CONTEXT.md` |
| 公开发布运行时 | 匿名读取发布快照、metadata、缓存与运行时呈现 | `apps/publisher-next/CONTEXT.md` |
| 平台后端 | 身份、权限、持久化、版本、发布与审计 | `server/CONTEXT.md` |
| Schema 契约 | schema 类型、迁移、校验、事件和生成规则 | `packages/lowcode-schema/CONTEXT.md` |

## 核心闭环

```text
登录 -> 项目 -> 页面草稿 -> 编辑器 -> schema 校验 -> 保存版本
     -> 发布快照 -> Next.js 公开发布运行时 -> 匿名访客
```

数据源模型只描述用户外部 API，不在平台数据库中创建或托管用户业务记录。AI 只产生 schema 或 patch，确认后才进入同一保存和发布链路。

## 稳定约束

- 编辑器页面根节点是 `Page`，store 兼容导出名是 `useComponetsStore`。
- schema 的迁移和校验规则由 `packages/lowcode-schema` 统一拥有。
- 公开页面只渲染 `publishedVersionId` 指向的发布快照。
- 公开发布运行时不执行 custom JS，不使用当前用户 token。
- Next.js 不直连 Prisma；公开快照仍由 NestJS 提供。
- AI 不绕过编辑器 store、保存、版本、发布和用户确认流程。
- 数据库模型只由 Prisma schema 和 migrations 管理。

## 高风险入口

- `src/editor/stores/components.tsx`：组件树、选择、历史和缓存。
- `src/editor/registry/component-config.tsx`：物料 interface 与 prod/dev implementation。
- `src/editor/runtime/Preview/index.tsx`：事件、变量、数据源和 custom JS 策略。
- `src/editor/runtime/public`：Vite 与 Next 共用的公开运行时 seam。
- `server/src/modules/pages`：页面草稿、版本、发布快照和缓存失效。
- `server/src/modules/projects/project-access.service.ts`：项目角色与访问规则。
- `packages/lowcode-schema/src`：跨运行时 schema 契约。
- `server/prisma/schema.prisma`：数据库事实来源。
