# 项目运行指南

## 环境

- Node.js 22
- npm
- Docker Desktop（用于 PostgreSQL 或完整容器环境）

所有依赖在仓库根安装：

```powershell
npm install
```

## 环境变量

```powershell
Copy-Item apps/editor-web/.env.example apps/editor-web/.env
Copy-Item apps/api-server/.env.example apps/api-server/.env
Copy-Item apps/publisher-web/.env.example apps/publisher-web/.env.local
```

关键配置：

| 应用 | 变量 |
| --- | --- |
| editor-web | `VITE_API_BASE_URL`、`VITE_PUBLISHER_SITE_URL`、`VITE_LOWCODE_HTTP_ALLOWED_ORIGINS` |
| publisher-web | `PUBLISHER_API_BASE_URL`、`PUBLISHER_SITE_URL`、`PUBLISHER_REVALIDATE_SECRET` |
| api-server | `DATABASE_URL`、`JWT_SECRET`、`FRONTEND_ORIGIN`、`UPLOAD_DIR`、AI provider 配置 |

## 源码启动

启动 PostgreSQL：

```powershell
docker compose -f infra/docker/docker-compose.yml up -d postgres
npm run prisma:generate
npm run prisma:deploy
```

三个终端分别运行：

```powershell
npm run dev
npm run dev:server
npm run dev:publisher
```

默认地址：

- 编辑器：`http://localhost:5173`
- API：`http://localhost:3000/api`
- API 健康检查：`http://localhost:3000/api/health`
- 发布站：`http://localhost:5174/publish/:publicId`

## Docker 启动

```powershell
docker compose -f infra/docker/docker-compose.yml up -d --build
docker compose -f infra/docker/docker-compose.yml ps
```

- 编辑器：`http://localhost:8080`
- API：`http://localhost:3000/api`
- 发布站：`http://localhost:5174`

停止服务：

```powershell
docker compose -f infra/docker/docker-compose.yml down
```

不要随意添加 `-v`，它会删除数据库和上传文件 volume。

## 数据库命令

```powershell
npm run prisma:generate
npm run prisma:migrate -- --name <migration-name>
npm run prisma:deploy
```

修改 `apps/api-server/prisma/schema.prisma` 后必须创建 migration。生产环境只执行 `prisma:deploy`。

## 验证

```powershell
npm run lint
npm run check:architecture
npm run build
npm run build:publisher
npm run build:server
npm run test
npm run test:e2e:editor
```

API smoke 需要已启动的 PostgreSQL、已应用 migration 和正在运行的 API：

```powershell
npm run smoke:api
```
