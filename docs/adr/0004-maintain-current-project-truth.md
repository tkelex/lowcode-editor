# 仓库文档只维护当前项目事实

仓库文档按长期职责收敛为产品、架构、接口、编辑器、开发、测试、安全和 ADR。README 只承担项目入口、目录说明、快速启动、常用命令和文档导航，不复制详细设计与运维内容。

保留仍约束当前实现、运行、部署和验收的项目事实；阶段性建设规划、已完成的演进记录、重复说明以及项目专属 AI 工具协作指南应删除或合并到对应的当前事实文档。`AGENTS.md`、`CONTEXT-MAP.md`、各业务上下文文档和 ADR 继续保留，分别承担仓库规则、上下文导航、局部模型和决策理由，不再额外维护一套重复的 AI 上手文档。

因此删除 `docs/agents/`、`docs/00-总览/AI快速上手.md`、`docs/00-总览/UI需求表达指南.md`、`docs/00-总览/项目上下文索引.md` 和 `docs/05-开发/多AI并行开发规范.md`。删除前将其中仍有效且尚未被记录的项目事实合并进 `AGENTS.md`、`CONTEXT-MAP.md` 或对应 `CONTEXT.md`，并同步清理仓库内引用。

删除阶段性总规划 `docs/01-产品/企业级低代码平台建设规划.md` 和已完成改造记录 `docs/04-编辑器/编辑器体验优化说明.md`。仍有效的技术栈、模块边界、产品约束和界面规则先合并到对应的当前事实文档，不保留“近期任务”“后续约定”一类会快速失效的章节。

`docs/01-产品/自然语言AI开发助手计划.md` 不整份删除，而是收敛为 `docs/product/ai-page-builder.md`。新文档只描述能力范围、schema 或 patch 输出、后端模型网关、输入输出校验、用户确认流程和安全边界；移除当前基础、路线图、近期执行顺序与下一步等阶段信息。

删除聚合式的 `docs/02-架构/技术决策记录.md`。NestJS、PostgreSQL、Prisma、JSONB、鉴权与权限等当前事实合并到架构或安全文档；需要长期保留理由的重要选择拆成独立 ADR；已被推翻的 typo 兼容、项目专属 skill 和 MCP 等决策，以及 Git 提交方式和学习总结，不再迁移。

将 `docs/04-编辑器/事件绑定系统设计.md`、`docs/04-编辑器/事件动作规划.md` 和 `docs/04-编辑器/事件能力矩阵.md` 合并为 `docs/editor/events.md`。新文档是事件 schema、动作类型、运行时行为、安全限制、物料能力和修改检查项的唯一事实来源，不保留实现优先级、后续规划和重复示例。

将 `docs/05-开发/CI与部署基础.md`、`docs/05-开发/GitHub与Netlify上线指南.md` 和 `docs/05-开发/部署与运维指南.md` 合并为 `docs/development/deployment.md`。新文档只维护三个应用当前有效的构建、环境变量、Docker/Compose、CI、上线与回滚流程；旧单体 Vite 或不再适用的 Netlify 步骤直接删除。`项目运行指南.md` 继续作为本地开发入口独立维护。

将 `docs/07-安全/安全规范.md` 和 `docs/07-安全/上线安全检查清单.md` 合并为 `docs/security/security.md`。正文维护鉴权、权限、密钥、CORS、上传、Custom JS、日志和数据库安全等规则，末尾保留一份与这些规则一致的上线安全检查清单。

将 `docs/06-测试与验收/功能演示流程.md`、`docs/06-测试与验收/上线验收清单.md` 和 `docs/06-测试与验收/AI-CRUD路由验收清单.md` 合并为 `docs/testing/acceptance.md`，按自动检查、核心编辑流程、发布流程、AI CRUD 专项和上线前检查组织，避免同一步骤在多份清单中重复维护。

删除 `docs/05-开发/Git工作流.md`。它主要是通用 Git 教程，并依赖已经失效的前端根目录与 `server/` 布局；项目特有的检查命令和安全约束由 README、`AGENTS.md` 与更新后的编码规范维护。

Git 已忽略的 `docs/01-产品/产品路线图.md`、`docs/08-复盘/` 和 `docs/09-学习资料/` 属于个人资料，迁移并合并到用户的 Obsidian vault 后从仓库工作目录移除；已失效的 `docs/10-协作/` 和 `docs/99-归档/` 直接删除。完成迁移后同步删除 `.gitignore` 中对应的历史规则，使仓库不再暗含一套未受版本控制的文档体系。

根 `README.md` 只保留项目用途与应用关系、精简目录树、环境要求与首次安装、常用 workspace 命令、核心文档链接。详细架构、功能清单、数据库说明、AI 工具流程与历史规划不在 README 重复维护；`docs/README.md` 只作为分类清晰的文档索引。
